自作アプリ一覧

作ったアプリ、まとめました。

個人開発したWebアプリを1ページに集約しました。すべてインストール不要、ブラウザで開くだけですぐに使えます。 気になるアプリがあれば、下のカードから試してみてください。

アプリ一覧

To-Doooon!

期限管理とGoogleカレンダー連携を備えた、シンプルなタスク管理アプリ。ブラウザのlocalStorageにデータを保存し、スマホのホーム画面にも追加できます。

アプリを開く 紹介ページ GitHub

小役カウンタ

パチスロの総遊技数と小役の出現回数を記録し、出現率を自動計算するスマホ向けアプリ。インストール不要、ブラウザだけで使えます。

アプリを開く 紹介ページ GitHub

名刺管理

スマホで名刺を撮影するだけでOCRが氏名・会社名・連絡先を自動入力。50音順・氏名順・会社名順で整理できる無料の名刺管理アプリ。

アプリを開く 紹介ページ GitHub

ニュースダイジェスト

NHKニュースをカテゴリ別に要約表示するWebアプリ。気になるニュースは元記事の全文へワンタップで移動可能。ニュースデータは20分おきに自動更新されます。

アプリを開く 紹介ページ GitHub

バイトシフト確認

カレンダーにバイトの開始・終了時間を入力するだけのシフト確認アプリ。休みの日は自動で色分けされ、時給を登録すれば給与も自動計算。音声入力にも対応しています。

アプリを開く 紹介ページ GitHub

※ 掲載しているアプリはすべてブラウザ内(localStorage)にデータを保存する個人開発ツールです。端末やブラウザを変えるとデータは引き継がれません。
